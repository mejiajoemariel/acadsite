Institutional File Naming Format Guide

Concepcion Holy Cross College, Inc.

Standard File Name Format

DOC SN NO. - FACULTY ALIAS - SUBMISSION CODE - CODE DESCRIPTION (SHORTEN) - CYS - SEMAY

Example:

SCS1-A.BALBERAN-002-GEC101-UTS-1BSCS-A-1AY2026-2027

Format Breakdown

Component Description Example
DOC SN NO. Document Serial Number from Program Head SCS1
FACULTY ALIAS First initial + surname A.BALBERAN
SUBMISSION CODE Assigned document type code 002
CODE DESCRIPTION Subject code + document type GEC101-UTS
CYS Course, Year, Section 1BSCS-A
SEMAY Semester and Academic Year 1AY2026-2027

Submission Codes

001 - Syllabus
002 - Class Records
003 - Table of Specification
004 - Item Analysis
005 - Final Grade

Important Reminders:
  • Follow exact format and order
  • No extra spaces or special characters
  • Verify DOC SN before submission
  • Ensure correct semester and academic year
